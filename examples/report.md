## 1. 方法学

本研究采用**不相称性分析(disproportionality analysis)**,这是药物警戒中筛查
疑似安全信号的常规定量方法。其核心思想是:如果某药物与某不良事件之间不存在
特殊的关联,那么该事件在"该药物报告"中的占比应当与在其他药物报告中的占比接近;
若前者显著更高,则提示可能存在待评估的信号。

对每一个"药物-反应"组合,按下列方式构造 2x2 列联表:

```
                    目标反应 a        其他反应         合计
    目标药物           a               b            n1 = a+b
    其他药物           c               d            n0 = c+d
    合计            m1 = a+c        m0 = b+d         N = a+b+c+d
```

其中 a/b/c/d 的含义为:

- `a`:数据库中**该药物**同时报告了**该反应**的报告数
- `b`:该药物报告了其他反应的报告数
- `c`:其他药物报告了该反应的报告数
- `d`:其余报告数
- `N`:该数据库中"药物-反应"报告对的总数(即全库报告数的近似)

计数字段来自 openFDA 的 `count=patient.reaction.reactionmeddrapt.exact` 聚合查询;
`a` 取自该药物反应分布中对应 PT 的计数,`n1 = a+b` 与 `m1 = a+c` 取自对应的
`meta.results.total`,因此不受单次聚合查询 `limit` 的截断影响。

**连续性校正**:当 2x2 表中出现 0 单元格时,对数或比值会出现除零。
此时对四个单元格**同时加 0.5**(Haldane-Anscombe 校正),仅在这种情况下启用。
该做法使估计值向无效值(PRR=ROR=1)收缩,相关行在结果表中标注 `corrected`。

## 2. 统计量定义

### 2.1 PRR(比例报告比, Proportional Reporting Ratio)

```
PRR = [ a / (a+b) ] / [ c / (c+d) ]
```

标准误与 95% 置信区间(对数正态近似):

```
SE(ln PRR) = sqrt( 1/a - 1/(a+b) + 1/c - 1/(c+d) )
95% CI     = exp( ln PRR +/- 1.96 * SE )
```

卡方检验(2x2 表 Pearson 卡方,自由度 1):

```
chi2 = N * (a*d - b*c)^2 / [ (a+b) * (c+d) * (a+c) * (b+d) ]
```

### 2.2 ROR(报告比值比, Reporting Odds Ratio)

```
ROR = (a / b) / (c / d) = a*d / (b*c)
SE(ln ROR) = sqrt( 1/a + 1/b + 1/c + 1/d )
95% CI     = exp( ln ROR +/- 1.96 * SE )
```

### 2.3 BCPNN 的 IC(信息成分, Information Component)

BCPNN(Bayesian Confidence Propagation Neural Network)由 WHO 乌普萨拉监测中心
(UMC)用于其信号检测。IC 定义为观测值与期望值之比的以 2 为底的对数:

```
IC      = log2( a / E ),  E = (a+b) * (a+c) / N
E(IC)   = log2( (a + g11)(N + a0)(N + b0) / [ (N + g)(a + b + a1)(a + c + b1) ] )
V(IC)   = 1/(ln2)^2 * [ (N - a + g - g11) / ((a + g11)(1 + N + g))
                       + (N - (a+b) + a0 - a1) / ((a+b+a1)(1 + N + a0))
                       + (N - (a+c) + b0 - b1) / ((a+c+b1)(1 + N + b0)) ]
IC025   = E(IC) - 1.96 * sqrt(V(IC))
```

先验超参数取 UMC 惯例的一组弱信息先验:g11=0.5, g=1.0, a0=1.0, b0=1.0, a1=0.5, b1=0.5。
在 N 较大时该式退化为 IC = log2(a/E)。**IC025 > 0** 表示在贝叶斯框架下
有 95% 的可信度认为观测数高于期望数,是常用的信号判据。

## 3. 信号判据

本报告采用的判据:PRR >= 2.0 且 chi2 >= 4.0 且 a >= 3 (EU 标准);ROR 95% CI 下限 > 1.0;IC025 > 0。

| 判据 | 阈值 | 出处 |
|---|---|---|
| PRR | PRR >= 2 且 chi2 >= 4 且 a >= 3 | 欧盟(EMA)对 PRR 的常规信号阈值 |
| ROR | ROR 的 95% CI 下限 > 1 | 荷兰 Lareb / 常规 ROR 判据 |
| IC | IC025 > 0 | WHO UMC BCPNN 判据 |

结果表中 `判据` 列以 `PRR`/`ROR`/`IC` 标识各自独立的命中情况,
`PRR+ROR+IC` 表示三条判据同时满足(证据相对更强的组合),`no` 表示未命中任何判据。

## 5. 局限性(Limitations)

本节是解读上述结果的必要前提,任何结论都不得脱离这些限制:

1. **自发呈报数据没有分母**。FAERS 收集的是自愿提交的报告,不存在暴露人群数
   (接受该药物治疗的患者总数),因此 PRR / ROR / IC **不是发病率、不是风险比、
   不是绝对风险**,也不能用来比较不同药物的安全性高低。
2. **不相称不等于因果**。本研究只能说明"报告中出现了超出背景水平的聚集",
   不能证明药物导致了该不良事件。信号需要经流行病学研究和临床评估后
   才能转化为安全性结论。本报告不构成任何医疗建议。
3. **报告偏倚(reporting bias)**。报告行为受事件严重程度、上市时间、媒体关注、
   监管行动、诉讼与文献报道等因素影响,新药与备受关注的药物更容易被报告。
4. **重复报告**。同一病例可能被患者、医生、企业分别提交,FAERS 中未完全去重,
   会同时抬高 a 与 b。
5. **适应症混杂(confounding by indication)**。某药物被用于的疾病本身可能
   导致该不良事件,从而产生虚假的不相称。
6. **事件与药物的分组口径**。反应使用 MedDRA 首选术语(PT)层级的精确匹配,
   同一医学概念的不同 PT(SMQs 未合并)会被拆散;药物名按 openFDA 规范化的
   `medicinalproduct` 精确匹配,复方制剂、商品名与拼写差异可能造成漏计或串计。
7. **计数口径为下限估计**。全库报告对总数 N 由按药物名聚合的前若干项求和得到
   (聚合接口 `limit` 上限为 1000),未覆盖报告数极少的尾部药物名;
   反应总报告数 m1 取自 `meta.results.total`,不受该限制。因此 N 略偏低,
   会使 IC 与卡方被轻微高估,PRR/ROR 的方向不受影响。
8. **多次比较**。对成百上千个组合同时检验会产生大量假阳性,
   本报告未做多重比较校正(药物警戒筛查阶段的惯例)。
9. **统计方法本身是筛查工具**。PRR/ROR/IC 的设计目的是"减少需要人工审阅的报告量",
   而不是"判定因果"。阈值是人为约定的经验值,不同机构使用的阈值并不统一。
10. **数据时点**。openFDA 数据为滚动更新,复现时结果会随后续报告累积而略有变化;
    本报告的生成时间与数据源标注时间见文首。
